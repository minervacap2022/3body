# 三体：王权 - 游戏说明

## 🎮 游戏简介

《三体：王权》是一款基于《三体》宇宙背景的单机策略决策游戏，玩法继承经典《王权》系列的核心机制。通过左右滑动/按键进行二选一决策，管理四大关键计量，在复杂的政治与科技博弈中生存并达成文明目标。

## 🌐 访问方式

### 方式1：通过主页Projects部分
1. 访问 https://www.panor.tech/
2. 点击导航栏中的 "Projects"
3. 找到 "三体：王权" 项目
4. 点击进入游戏

### 方式2：直接访问
- 游戏地址：https://www.panor.tech/3body/

## 🎯 游戏特色

- **四大计量系统**：科研、民心、军备、资源，需要保持平衡
- **黑暗森林风险**：隐藏计量，过高会触发灭顶之灾
- **多线剧情**：面壁者、破壁人、ETO、执剑人等不同阵营的复杂博弈
- **时代演进**：从"锁死物理"初期到文明抉择的完整时间线
- **16种结局**：多种胜利和失败路径，高复玩性

## 🎲 游戏玩法

### 基本操作
- **鼠标**：点击左右选项按钮
- **键盘**：使用 ← → 方向键选择
- **触摸**：移动端支持左右滑动

### 游戏目标
在四大计量不触底/触顶的前提下，达成以下任一胜利条件：
1. 建立可持续威慑并保持稳定
2. 完成"文明分流"宏案
3. 通过外交降低黑暗森林风险

### 难度等级
- **简单**：负面效果较小，死亡阈值宽松
- **普通**：标准平衡
- **困难**：负面效果增强，死亡阈值严格
- **疯狂**：极端挑战模式

## 🏆 胜利条件

达成以下任一Meta目标即可获得胜利：

1. **威慑稳态**：建立可持续威慑并稳定维持指定回合数
2. **文明分流**：成功实现地表留守+曲率远征的双重保险策略
3. **沉默协定**：通过外交手段签订长期和平协议，降低黑暗森林风险

## 🗂️ 时代与阵营

### 时代进程
1. **锁死物理初期**：基础物理被锁定，科技发展受阻
2. **面壁/破壁期**：面壁计划与破壁人的智力对抗
3. **威慑建立期**：建立对三体的战略威慑
4. **执剑人时代**：威慑体系的维护与传承
5. **远征/危机期**：深空探索与威慑失效风险
6. **文明抉择期**：人类文明的最终方向选择

### 主要阵营
- **面壁者**：承担拯救人类使命的战略规划者
- **破壁人**：试图破解面壁计划的三体协作者
- **ETO（地球三体组织）**：支持三体入侵的人类组织
- **联合国/执剑体系**：全球治理与威慑维护机构
- **军工复合体**：军事工业与防务研发机构
- **学术界**：科研院所与高等学府
- **媒体**：信息传播与舆论引导机构
- **企业集团**：工业生产与资源控制集团
- **航天局**：太空探索与深空监测机构

## 🎯 开局场景

游戏以叶文洁在红岸基地的关键抉择开始：

1. **异常信号捕获**：接收到外星窄带脉冲信号
2. **劝阻警告**：收到不建议回应的低功率传输
3. **回发决策**：选择静默、试发或正式回发
4. **载荷选择**：确定回发内容的性质和规模
5. **社会影响**：应对决策引发的体制和舆论反应
6. **分支确立**：开启不同的文明发展路径

## 🔧 故障排除

### 游戏无法加载
1. 检查浏览器是否支持HTML5和ES6
2. 尝试刷新页面
3. 检查浏览器控制台是否有错误信息

### 游戏卡在loading界面
1. 等待5-10秒让游戏完全加载
2. 检查网络连接
3. 尝试使用不同的浏览器

### 存档丢失
1. 检查浏览器是否启用了localStorage
2. 尝试在隐私模式下运行游戏
3. 清除浏览器缓存后重试
