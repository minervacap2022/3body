# 三体：王权 - Three Body: Reigns

## 🎮 Play the Game

**Game URL**: https://www.panor.tech/3body/

## 📁 Files

This directory contains only the production files:

- `index.html` - The complete game (single-file, no dependencies)
- `README_GAME.md` - Game documentation in Chinese
- `README.md` - This file

## 🎯 Game Features

- **266 event cards** covering the complete Three Body universe storyline
- **4 resource meters**: Science, Public Opinion, Military, Resources
- **16 different endings** with multiple victory paths
- **Auto-save** using localStorage
- **Responsive design** for PC and mobile

## 🎲 How to Play

1. Visit https://www.panor.tech/3body/
2. Wait for the game to load (about 2-3 seconds)
3. Make decisions by:
   - Clicking left/right buttons
   - Using arrow keys (← →)
   - Dragging cards left/right (PC)
   - Swiping left/right (mobile)

## 🔧 Technical Details

- Single HTML file with inline CSS/JavaScript
- Zero external dependencies
- Works offline after first load
- Supports all modern browsers

## 📱 Compatibility

- **PC**: Chrome 70+, Firefox 65+, Safari 12+, Edge 79+
- **Mobile**: iOS Safari 12+, Android Chrome 70+
